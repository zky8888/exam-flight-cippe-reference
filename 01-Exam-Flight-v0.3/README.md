# Exam Flight 备考陪练

版本：0.3 试用版｜2026-10-04

一个可以装进 Codex 或 Claude 的备考技能。装好之后，你告诉 AI 你要考什么，它会在一个独立文件夹里为你建立专属的备考项目，带你找题、拆题、学习、做题、修错、回测和模拟，并把真实进度存成文件。下次打开，说一句“继续”就能接着学。

这套方法来自一位考生备考 CIPP/E（欧洲数据保护认证）的真实经验，经过整理，可以用在其他考试上。

---

## 一、这个系统到底在做什么

### 一句话

**先看考试怎么考，再回书里学；学完，马上用题检验。** 原作者把它叫做“考中学、学中考”。

很多人备考的顺序是：先把教材从头读一遍，再去做题。问题是，读的时候不知道哪些内容会被怎么考，读完也不知道自己会不会。这套方法反过来：先用真题弄清楚考试要求你会做什么，再带着问题回到教材里学，学完马上用题检验，错了就找到错在哪一步，修好后隔天再测。

### 它会帮你做的七件事

| 步骤 | AI 做什么 | 你需要做什么 |
|---|---|---|
| 1. 找题 | 帮你整理有来源的真题或可信题库，标清楚来源 | 提供你手上的题目材料 |
| 2. 拆题 | 逐题分析：要你做什么判断，考哪些知识点，每个选项在试探什么 | 不用参与，这是 AI 的备课工作 |
| 3. 对接教材 | 把每个知识点和教材的具体章节、原文对上 | 提供教材 |
| 4. 排主题 | 把知识点聚合成主题，按依赖关系排出学习顺序 | 确认先学哪块 |
| 5. 讲解和做题 | 讲清一个主题，然后让你闭卷独立做这个主题的原题 | 听讲、做题、写一句理由 |
| 6. 修错 | 找到你的推理断在哪一步，回到教材原文修好 | 跟着把正确的推理说一遍 |
| 7. 回测 | 隔天换个情境再测，确认真的记住了 | 按时回测 |

### 第一天就能走完一圈

完整拆完一整套真题要好几天。为了不让你干等，第一天会先挑一小块（比如一个章节相关的题），把上面七步完整走一遍。之后再一块一块往外扩，直到覆盖整套题。

### 一个例子：一位考生的前两天

小林准备考一级建造师的建筑实务，教材和三年真题都有，每天晚上能学一小时。

- **第一天**：他在一个新文件夹里打开 Codex，说了考试、时间和材料。AI 建好项目文件，看了三份真题，建议先学“网络计划的关键线路”，因为每年都考，后面内容也依赖它。AI 先讲了 15 分钟，中间给了个小例子让他判断；然后切换到闭卷做题，他做了 3 道，错了 1 道。AI 发现他总在比较“单个工序时间”而不是“路线总长”，用理由链帮他修正，并把这个点排进第二天的回测。结束时 AI 告诉他：今天完成了什么、还剩什么、明天第一步做什么。
- **第二天**：他打开同一个文件夹，说“继续”。AI 读了进度记录，先给他做了一道关于关键线路的新情境题，不给提示。这次他做对了，而且理由完整。AI 把这个点记为“跨日保持”，然后接着昨天没做完的题继续。

完整的示范对话见 [首课示范对话](exam-flight/references/first-session-example.md)。

### 它为什么能“量身定做”

你的考试信息、材料清单、做题记录、错因、回测安排、学习习惯，都存在你自己的项目文件夹里。项目里的 `AGENTS.md`（Codex 自动读取）和 `CLAUDE.md`（Claude Code 自动读取）告诉 AI 这是谁的项目、每次先读什么、你们约定好的习惯。所以 AI 每次打开都能接上，而且越用越贴合你。

## 二、它不能做什么

在开始之前，请先了解这些边界。它们不是功能缺陷，而是这套方法刻意守住的原则。

1. **不替你做题。** AI 不会替你选答案，也不会在你还没作答时就给你打分。你没做的题，记录里就是“未答”。
2. **不保证你能通过考试。** 它能帮你更有条理、更高效地准备，但学习效果取决于你实际的投入和表现。
3. **不能代替官方信息。** 考试日期、题型、分值、及格线、现行规范，都要以官方发布的为准。AI 查不到或没核对的，会标“待确认”，不会凭印象给你一个数字。
4. **不把 AI 出的题说成真题。** 来自官方的、来自题库的、AI 自己出的题，都会分开标注。AI 出的练习题只能帮你练，不能当作真题用来判断你的水平。
5. **不把记忆说成教材内容。** AI 会区分“教材原文写着”和“我的理解是”。没有读到你的教材时，它会告诉你“这部分需要和你的教材核对”。
6. **不把“讲过”当成“会了”。** 讲过的主题、做过的题、隔天还能做对的能力，会分开报告。当堂在提示下改对，不算已经掌握。
7. **没有材料时能做的有限。** 你没有教材，它只能给一般性的解释；没有真题，它只能先搭知识框架。它会告诉你缺了什么、影响什么。
8. **不处理版权问题。** 你的教材和题库只供你自己学习。这个技能包里不含任何教材或题库内容，分享你的项目给别人时，请不要把受版权保护的材料一起发出去。

## 三、应该怎么做

### 第 1 步：安装

把包里的 `exam-flight` 文件夹（里面有 `SKILL.md` 的那个）放到对应工具的技能目录。

**Codex**

在终端里运行（假设你已经解压到当前目录）：

```bash
mkdir -p ~/.agents/skills
cp -R exam-flight ~/.agents/skills/
```

然后重启 Codex。在对话里输入 `$exam-flight` 可以直接调用，也可以直接说“帮我备考”，Codex 会自动识别。如果你用的是较早版本的 Codex，技能目录可能是 `~/.codex/skills/`，识别不到时可以试试放在那里，或查看 Codex 的官方说明。

**Claude Code**

```bash
mkdir -p ~/.claude/skills
cp -R exam-flight ~/.claude/skills/
```

然后重新打开 Claude Code。输入 `/exam-flight` 可以直接调用，也可以直接说“帮我备考”。

**Claude 网页版或桌面版**

在设置里找到技能（Skills）的上传入口，上传包里的 `exam-flight.zip`。注意：普通网页聊天不能把文件存到你的电脑上，AI 会把要保存的内容整理成文本让你自己复制保存。想要自动保存进度，建议使用 Codex、Claude Code，或者 Claude 桌面版中可以连接本地文件夹的模式。

### 第 2 步：准备一个文件夹和材料

1. 在电脑上新建一个文件夹，比如 `我的备考`；
2. 在里面建一个 `materials` 文件夹，把教材、真题、题库、官方大纲放进去，文件名写清版本或年份；
3. 在这个文件夹里打开 Codex 或 Claude Code。

没有材料也可以开始，AI 会先帮你理清考试要求和需要准备什么。

### 第 3 步：第一次开口

直接复制下面这段，把括号里的内容换成你的情况：

> 请用 exam-flight 带我备考。我准备参加【具体考试和科目】，考试时间是【日期，或者大概几个月后】，手上有【教材、真题、题库等材料，放在 materials 文件夹】，每天大约能学【时长】，目前基础是【零基础／学过一遍／考过没过】。先带我开始第一步。

考试名称越具体越好。“一级建造师 建筑工程管理与实务”比“建筑类考试”好，“小学数学教师资格 笔试科目三”比“教资”好。

### 第 4 步：第一次会发生什么

1. AI 确认你的考试、时间、材料，没核对的官方信息标“待确认”；
2. 在你的文件夹里新建一个考试项目文件夹，放好记录文件；
3. 看你的真题，建议第一块从哪里开始，并说明理由；
4. 如果时间允许，当场开始第一个主题：讲解、小回顾、独立做题、反馈；
5. 结束时告诉你：完成了什么、记录在哪、还剩什么、下次第一步。

第一次可能需要 1 个小时左右。如果时间不够，可以只建档，下次再开始学。

### 第 5 步：之后每次怎么用

在同一个考试项目文件夹里打开 AI，说“继续”或“今天学什么”就行。AI 会读进度，先安排到期的回测，再接着上次的地方往下走。

其他常用的说法：

- “我今天只有 20 分钟” → AI 会缩小今天的范围；
- “这道题我为什么错了” → AI 会请你说出当时的理由，帮你找断点；
- “帮我做一次模拟” → AI 会先核对真实考试的题型和时长；
- “直接给我模板” → AI 会一次生成整套空白项目文件；
- “今天先到这里” → AI 会记下准确位置，下次从这里接着做。

### 前三天大概是什么节奏

- **第 1 天**：建档，挑第一块，走完一圈：讲解、做题、修错，排好回测。
- **第 2 天**：先做第 1 天的回测，再继续第一块剩下的题，或开始第二块。AI 在背后继续拆整套真题。
- **第 3 天**：回测 + 新主题。到这时你应该能感觉到节奏，可以开始提出调整意见。

## 四、怎么磨合成你自己的

这套方法里很多设置都可以调，原作者的习惯不会强加给你。

### 可以调整的设置

| 设置 | 默认 | 可以改成 |
|---|---|---|
| 每批题数 | 5 道 | 3 道、10 道，按你的时间和题目难度 |
| 作答时写理由 | 一句话 | 只写关键词，或者写完整推理 |
| 记录信心 | 0 到 3 分 | 不记录 |
| 复习间隔 | 第二天、再隔两天、之后混合抽查 | 按离考试的天数调整 |
| 讲解风格 | 先讲例子再讲规则 | 更短、更多例子、更多图表 |
| 语言 | 中文 | 题目用原文、反馈用中文等 |
| 题量目标 | 主题相关的题全部做 | 抽样，但会写明抽了哪些、没抽哪些 |

### 怎么提调整

直接跟 AI 说就行，比如“讲解太长了，每段短一点”“每批改成 3 题”“不用记录信心了”。AI 会把调整写进项目 `AGENTS.md` 里的“磨合约定”，下次自动沿用。

每次收课时 AI 会问一句今天的节奏怎么样，这是调整的好时机。

### 什么时候该调

- 经常做不完一批题 → 减少每批题数；
- 讲解时容易走神 → 要求每段更短、多给例子；
- 回测总是很轻松 → 可以拉长复习间隔；
- 离考试很近了 → 改成抽样，优先补高价值的缺口。

## 五、常见卡点

**我没有电子版教材，只有纸质书。**
可以拍照或扫描你正在学的那一章放进 materials 文件夹。也可以先不对接教材，AI 会标明哪些解释还需要和教材核对。

**真题太多了，全部拆完要很久。**
这是正常的。第一天只挑一小块，之后每天拆一部分。AI 每次会告诉你整体进度。时间实在不够，可以改成抽样。

**AI 的记录太啰嗦了。**
跟它说“记录简化一点，收课时只报四件事”。核心记录（你的第一次答案、错因、回测日期）建议保留。

**AI 好像忘了上次的进度。**
确认你是在同一个考试项目文件夹里打开的 AI，并且里面有 `01-当前进度.md`。可以直接说“先读 01-当前进度.md”。

**我想跳过基线测试，直接开始学。**
可以。记录里会写“本人选择跳过”，学习计划先按暂定的来，之后根据你做题的表现调整。

**我考的是面试或实操。**
可以用，但需要你提供录音、录像或文字实录，AI 才能给出有依据的反馈。详见 [换考试怎么用](exam-flight/references/adaptation.md)。

**AI 给的答案和题库答案不一样。**
这时 AI 应该列出两边的依据，并把这道题标为“有争议”，暂时不用它来判你的对错。你可以对照教材原文自己判断，或查官方说明。

## 六、术语小词典

| 词 | 意思 |
|---|---|
| 首答 | 你第一次独立作答时的答案和理由，原样保存，之后改对了也不覆盖 |
| 曝光 | 你在作答前已经看到过这道题的答案。看过答案再做对，只算复习 |
| 回测 | 隔一段时间，换个情境、不给提示，再测一次同一个知识点 |
| 跨日保持 | 隔天以上，不提示也能做对。这是“真的记住了”的证据 |
| 去重 | 同一道题做了好几次，题目进度只算一次 |
| 全量／抽样 | 全量是约定范围内的题全部做；抽样是挑一部分做，并写明挑了哪些 |
| 对接表 | AI 备课用的表格，把每道题和教材原文对上。含答案，做题前不给你看 |
| 第一圈 | 第一天挑一小块，把找题到回测的流程完整走一遍 |
| F–R–L–C | 理由链：决定性事实（F）、规则（R）、两者怎么连上（L）、结论（C）。详见 [推理与错因](exam-flight/references/reasoning.md) |
| 磨合约定 | 你和 AI 约定的学习习惯，写在项目的 `AGENTS.md` 里，下次自动沿用 |

## 七、包里有什么

```
Exam-Flight-v0.3/
├── README.md                    你正在读的这份说明
├── 版本与试运行记录.md           每个版本改了什么，测试到什么程度
├── exam-flight.zip              给 Claude 网页版或桌面版上传用的技能压缩包
└── exam-flight/                 技能本体，复制到技能目录
    ├── SKILL.md                 AI 读取的主说明
    ├── agents/openai.yaml       Codex 界面显示用的信息
    ├── references/              分步骤的详细说明（AI 按需读取）
    │   ├── startup.md               新建项目的六个步骤
    │   ├── question-to-textbook.md  拆题和对接教材
    │   ├── session.md               日常上课、模拟、收课
    │   ├── reasoning.md             F–R–L–C 理由链和七类错因
    │   ├── evidence.md              记录什么、进度怎么算
    │   ├── adaptation.md            换考试怎么调整
    │   └── first-session-example.md 一次完整首课的示范
    └── assets/project-starter/  新项目的起步文件，AI 会复制到你的考试文件夹
```

不装技能也可以先看看：打开 `exam-flight/SKILL.md` 和 `references/first-session-example.md`，就能大致了解它怎么工作。
