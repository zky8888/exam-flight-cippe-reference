# 版本与试运行记录

## 0.3 版（2026-10-04）

### 改了什么

1. **全部展开重写。** 0.2 版语言压缩严重，很多规则只有结论没有解释。0.3 版每条规则都写明是什么、为什么、AI 实际该怎么说或怎么做，并配了示例。
2. **README 重写。** 分成三大部分：这个系统在做什么、不能做什么、应该怎么做；增加了安装步骤（Codex、Claude Code、Claude 网页版或桌面版）、第一次开口的模板、前三天节奏、磨合方法、常见卡点和术语小词典。
3. **新增首课示范对话**（`references/first-session-example.md`），让 AI 看到一次完整首课的节奏。
4. **找回 F–R–L–C 理由链和读题顺序。** 这是原作者方法里最有辨识度的部分，0.2 版里缺失，0.3 版放回 `reasoning.md`，并扩展到计算、案例和写作题。同时加入“同一错误第二次出现时换一种讲法”的规则。
5. **新增“第一圈”安排。** 主线仍是先拆题、再对接教材，但第一天先挑一小块完整走一遍，之后再逐步扩到整套题集，让新学习者当天就能学到东西。
6. **新增“照顾注意力的上课方式”。** 开课先给路线、一次只问一个问题、讲解分段、按状态缩放、结束问反馈。
7. **项目落地方式具体化。** 原来的单个模板拆成 `assets/project-starter/` 下的一组起步文件，包括会被 Codex 和 Claude Code 自动读取的 `AGENTS.md` 和 `CLAUDE.md`，让学习者下次打开能直接接上进度。
8. **目录调整。** 技能文件夹提到第一层，可以直接复制到技能目录；另附 `exam-flight.zip` 供上传。

### 测试到什么程度

- 已检查：技能名称和描述格式、文件内链接是否都能打开、压缩包完整性。
- 安装路径按 Codex 和 Claude Code 当前公开说明编写，尚未在两个工具里实际安装验证。
- **尚未进行真实试用**：没有让一个没见过这个包的 AI 实际执行，也没有真实学习者参与。

### 下一步建议

找一个真实考试和一位真实学习者，至少完成：一个主题的讲解、独立做题、修错，以及第二天的回测。重点观察：

- 第一次开口后，多久能开始学到东西；
- AI 是否被记录要求拖慢节奏；
- 第二天能否顺利接上进度；
- 磨合约定是否真的被沿用。
