# 推理与错因：怎么看懂学习者错在哪一步

这份文件讲四件事：理由要写成什么样（F–R–L–C 理由链）、长题怎么读、知识卡怎么做、错题怎么诊断和修复。

核心观点是：**判分不能只看选项对不对，要看理由链完不完整。** 选对了但理由是蒙的，到了考场换个说法就会错。

---

## 一、F–R–L–C 理由链

这是这套方法最核心的工具，来自原作者在法律类考试中的实践，可以推广到大多数考试。

### 四个环节

| 环节 | 含义 | 要回答的问题 |
|---|---|---|
| **F（Fact）决定性事实** | 题目里真正决定答案的那个事实 | 如果删掉或反转题干里哪个事实，答案就会变？ |
| **R（Rule）规则** | 这个事实对应的规定、原理、公式或例外 | 这里适用哪条规则？ |
| **L（Link）连接** | 事实怎样触发、满足或排除这条规则 | 这个事实凭什么让这条规则适用或不适用？ |
| **C（Conclusion）结论** | 得出的结论，强度要和规则一致 | 结论是“必须”“可以”还是“可能”？ |

### 推荐的理由写法

> 决定性的事实是 ___。
> 根据 ___（规则），这意味着 ___。
> 所以 ___。

不要求学习者机械套模板，熟练之后能用自己的话说清四个环节就行。

### 最常见的问题：从事实直接跳到结论

学习者经常这样写：“因为题目说了 XX，所以选 B。”这只有 F 和 C，中间的 R 和 L 缺了。

**即使选对了，也要标“答对但理由链不完整”，不能直接算掌握。** 反馈时只补缺的那一环，然后让他不看选项，自己把完整的链重新说一遍。

### 换到其他题型

| 题型 | F | R | L | C |
|---|---|---|---|---|
| 规则判断（法规、管理类） | 决定性事实 | 规定或例外 | 事实如何满足或排除规定 | 结论及其强度 |
| 计算 | 已知条件和数据 | 公式及其适用前提 | 代入、单位换算、步骤 | 结果及合理性检查 |
| 案例分析 | 材料中的关键事实 | 相关规定或技术要求 | 事实与要求的对照分析 | 判断和改正建议 |
| 论述写作 | 材料或题目给出的情境 | 理论、观点或依据 | 依据怎样解释这个情境 | 论点和结论 |

面试和实操类考试不适合硬套这个链条，按 [换考试怎么用](adaptation.md) 处理。

## 二、长题怎么读：先看问题，再找事实

题目越长，越容易被无关信息带偏。推荐的读题顺序：

1. **先读问句和选项**：圈出问句里的动作词（比如“必须”“首先”“最可能”“不正确的是”），确认它到底在问什么；
2. **列出相关的人或物**：只列和这一问有关的主体，不复述整个故事；
3. **找关系**：谁对谁做了什么、先后顺序是什么、数据或物料从哪到哪；
4. **聚焦扫描**：回到题干里和问句关键词相关的段落，再往前补读一段上下文。其他段落先放一边，只有在需要排除某个选项时再看。

这只是**阅读和注意力的顺序**，题目照样完整展示，不删减、不改写。反馈时可以告诉学习者哪些事实是这一问的关键、哪些是给其他小问准备的背景，但不能在他作答前替他筛选。

## 三、知识卡

讲完一个主题后，把它整理成一张知识卡，放进 `05-知识卡.md`。每张卡分四层：

1. **正式规则**：规定或模型本身，适用范围、前提条件、例外；
2. **大白话**：这条规则在解决什么问题，用一句话说清；
3. **正例、反例和单条件变化**：一个符合的例子，一个不符合的例子，再改变一个条件看结论怎么变；
4. **考试触发点和边界**：看到什么信号要想到这条规则；到什么地方就该停，不要过度推广。

如果规则内部关系比较复杂，可以画成结构：**概念（是什么）→ 关系（谁和谁怎么联系）→ 条件和顺序（满足什么、先后如何）→ 测试（改变哪个条件结论会变）**。

开放性的评价题（比如“是否合理”“风险高低”）不能硬写成“满足 A 和 B 就一定是 C”，要写成需要考虑的因素和证据强弱。题目没给的事实，保持“未知”，不要自己补。

## 四、选择题的做法

### 步骤

1. 锁定问句要你做什么；
2. 把每个选项当成一个待验证的说法，而不是“哪个看着对”；
3. 找出能决定答案的最小规则；
4. 把题干事实对到规则上；
5. 检查关键的连接（L）成不成立；
6. 做出选择，然后停下，不要无限扩展。

最难的是最接近的两个选项，要重点比较。其他选项只要找到足以排除的理由就够了。

### 简短输出

熟练之后，理由只需要三句：选哪个、决定性事实怎样满足规则、最接近的那个备选错在哪一步。完整步骤用于初学和诊断，稳定之后不要机械照抄。

## 五、七类错因

找错因时，先看学习者原来的答案和理由，找到**最早出错、而且最影响结论的那一步**。

| 错因 | 表现 | 修复方法 |
|---|---|---|
| **想不起来** | 记不起概念或完整规则 | 先恢复意思，再让他闭卷自己说一遍 |
| **答非所问** | 回答的是别的对象或别的问题 | 让他重写一遍“这题到底问什么” |
| **读错事实** | 漏看、看错，或者自己补了题目没给的条件 | 回到题面，找出原文 |
| **用错规则** | 选错了规则，或者规则的前提理解错了 | 读教材原文，比较两条相近规则的边界 |
| **关系搞错** | “必须”和“可以”、“全部”和“部分”、充分和必要等搞混 | 只改变一个条件，让他判断结论变不变 |
| **顺序搞错** | 步骤、前提或时间先后颠倒 | 写出最短的步骤链 |
| **推理缺环** | 从事实直接跳到结论，中间缺依据 | 追问“这一步凭什么”，补上 R 和 L |

另外还有几个辅助标签：语言理解问题、超时、注意力失误（比如选项和理由对不上）、理由未观察到。这些单独标注，不和知识性错误混在一起。

**题目本身有问题，单独处理，不算学习者的错。** 只看到一个选项字母、没有理由时，不要推断深层错因。

### 反馈的结构

1. 他原来的推理链是什么；
2. 断在哪里；
3. 主要错因（有证据的话再加一个次要错因）；
4. 最短的正确推理链；
5. 相邻的边界（容易混的地方）；
6. 一个只改变一个条件的小测试；
7. 下次什么时候验证。

### 优先修哪些

- 高信心却答错的（说明他以为自己会，最危险）；
- 隔天又错的；
- 会影响很多道题的基础缺口。

### 同一个错误第二次出现时：换一种讲法

同一个错误连续出现两次，不要用同样的方式再讲一遍。换一档：

文字定义 → 只改一个事实的对比情境 → 画图或讲故事 → 不看选项自己重建 → 隔天回测

至少换一档，看哪种方式对这个学习者有效，有效的方式可以写进磨合约定。

## 六、训练的三个阶段

1. **回忆**：能不能把规则或步骤说出来；
2. **执行**：能不能用在一道题上；
3. **排除**：能不能在相近选项中排除错误的那个。

哪个阶段失败，就只修那个阶段。

当场修好不代表已经掌握，跨日回测照样要做。也不要对每道错题无限地出变式题，修到能独立做对、排好回测就够了。
