# 记录与进度：记什么、怎么算、怎么自查

这份文件说明每类记录要写什么，进度怎么计算，以及收课前怎么自查记录有没有问题。

如果学习者已经有自己的记录方式，沿用他的字段和格式，不强迫迁移。下面是新项目的最低要求。

---

## 一、六类记录分别记什么

### 1. 考试档案（`00-考试档案.md`）

考试名称、科目、年份或地区、日期、官方范围和规则的来源、每天能学多久、还不知道的事情。

### 2. 材料（`00-考试档案.md` 的材料清单）

每份材料一个编号，写清类型、版本、页码或链接、你能不能读到、实际读了哪些部分。

### 3. 题目（`02-题目教材对接表.md`）

固定编号、来源位置、是原题还是改编或 AI 自拟、准备状态、题库给的答案、你核对后的结论和依据、主次知识点、有没有争议。

### 4. 作答（`03-作答记录.md`）

每一次作答单独一行，包括：

- 作答编号（每次都不同）和题目编号；
- 日期；
- 模式：基线、独立练习、回测、模拟；
- 学习者原来的答案和理由（照抄，不改写）；
- 对错和判分依据；
- 有没有给过提示，有没有提前看到答案；
- 信心分及来源（本人说的，还是你推测的）；
- 用时（没计时就写“未知”）。

### 5. 修复（`04-错因与回测.md`）

原来的推理链断在哪、主要错因、做了什么修复、提示后的表现、下次什么时候验证。

### 6. 回测（`04-错因与回测.md`）

要测的规则或能力、日期、优先级、要测的是哪个连接、实际结果、有没有提示。

### 关于“未知”

不知道的就写“未知”，**不要编造时间或信心**。学习者自己说的信心优先。如果是你根据他的表达推测的信心（比如 0 到 3 分），要标“推测”，并允许他纠正。**不能根据答对答错反推他的信心。**

## 二、三条进度分开算

| 进度 | 算什么 | 不算什么 |
|---|---|---|
| **知识进度** | 哪些主题已经接触、已经讲解 | 不代表会做题 |
| **题目进度** | 约定范围内的原题，有多少道学习者真正独立作答过，重复做只算一次 | 讲过的题、展示过的题、提示后改对的题、改编题、AI 自拟题 |
| **能力证据** | 学习者能否独立做对、隔天还能否做对 | 当堂在提示下改对 |

要计入题目进度，必须满足：题目和来源明确、学习者真正作答了、符合项目的判分规则。有争议的题、改编题、AI 题另外记录。回测重复做同一道题，不增加题目进度。

---

## 三、能力证据的四个层次

1. **当堂理解或提示后修复**：讲完能懂，提示后能改对；
2. **同日独立迁移**：同一天换一道题，不提示也能做对；
3. **跨日保持**：隔天或更久，不提示也能做对；
4. **限时混合执行**：在限时、混合主题的情况下也能做对。

可以描述“目前证据到了第几层”，但不要把这个框架说成标准化的评分量表。

一个子规则有证据，不代表整个主题都会了。之前做对、后来又错了，两条记录都保留，不要覆盖旧的证据。

---

## 四、收课前的自查清单

每次收课前过一遍：

- [ ] 说“完成了”的每一项，都能在记录里找到对应的真实作答？
- [ ] 全量目标的清单逐题核对过了？抽样目标写明了抽样范围和总数？
- [ ] 待核验和有争议的题，没有算进“完成”？
- [ ] 学习者第一次的答案没有被修复后的答案覆盖？
- [ ] 教学时的小回顾和独立做题没有混在一起算？
- [ ] 明天第一步、回测日期、暂停位置都写清楚了？
- [ ] `01-当前进度.md` 已经更新？

这份清单只检查记录是否一致，**不能证明学习有效，也不能证明能通过考试**。如果学习者的项目有更严格的验收要求，按项目的要求执行。
